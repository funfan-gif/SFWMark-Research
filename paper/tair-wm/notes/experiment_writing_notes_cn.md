现在的文章主要研究：

> 图像经过攻击后，怎样从图像中恢复用于水印判别的特征，以及怎样评价这些特征与密钥模板之间的关系。

具体流程是：

1. 对待检测图像进行 VAE 编码。
2. 使用扩散反演恢复初始噪声的估计。
3. 提取 HSQR 对应的频域特征。
4. 根据任务，执行水印验证或密钥识别。



| 前半篇的主张                  | 通俗理解                                                   | 实验应该回答的问题                                           |
| ----------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------ |
| 残差引导的 Exact-DDIM 精修    | 让每一步反演得到的候选，更符合对应的去噪重建关系           | 在相同评分规则下，更换反演是否改善了最终检测？局部残差实际改善多少？ |
| 协方差感知的 Mahalanobis 验证 | 根据正确密钥残差的变化规律，重新评价不同偏差的大小与相关性 | 在相同恢复特征下，Mahalanobis 是否比 CL1、L2、Diag 更适合验证？ |
| 按任务配置不同评分            | 验证和识别提出的问题不同，允许它们使用不同判别规则         | 为什么验证选择 Mahalanobis，而识别保留 CL1？两种任务的实验表现是否确实不同？ |

## 指标地位

| 指标                         | 它回答什么问题                                        | 我建议的位置           |
| ---------------------------- | ----------------------------------------------------- | ---------------------- |
| **TPR@严格 FPR<1%**          | 在低误报约束下，能检出多少带水印样本？                | 验证主指标             |
| **AUC**                      | 两类样本的评分总体上能否分开？                        | 验证辅助主指标         |
| **Id-Acc**                   | 正确密钥能否在候选集合中排第一？                      | 识别主指标             |
| **Frozen TPR**               | 独立校准后固定阈值，实际检出多少？                    | 与 Frozen FPR 配对展示 |
| **Frozen FPR**               | 同一固定阈值产生多少误报？                            | 与 Frozen TPR 配对展示 |
| **Frozen Balanced Accuracy** | 固定阈值下，正负两类表现的综合概括                    | 辅助或附录             |
| **MaxAcc**                   | 在测试 ROC 上选择最佳阈值时，能取得多高的平衡准确率？ | 附录或补充分析         |
